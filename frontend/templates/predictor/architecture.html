Model guide

How OpenFold3 predicts a structure

OpenFold3 predicts the 3D structure of a protein from its sequence in three stages: it first builds rich representations from an alignment of homologous sequences (MSA) and known similar structures (templates), then refines them in a long reasoning trunk called the Pairformer, and finally generates atom coordinates by diffusion, starting from a noisy point cloud that it progressively denoises into the final structure. The attention explorer looks inside two of these stages to show which residues the model links together.

Inside a Pairformer block

the same block is repeated 48 times, with different weights each time

The dashed arrow shows that the pair representation z acts as a bias steering the self-attention on s: this is how the Pairformer connects "which residues interact" (z) with "how to update each residue" (s). Triangle multiplication is not attention (no softmax over weights), so the tool does not analyse it.

The 4 maps available in the explorer

what each one shows and how to read it

Pairformer self-attention

For each residue, which other residues it directly "looks at" to update its own representation. Conceptually the closest to a classic protein language model attention map (ESM-style).

48 blocks · 16 heads · N×N matrix

Triangle attention (starting)

For each residue pair (i, j), how much a third residue k influences that pair, starting from i. Captures three-body geometric constraints, a hallmark of AlphaFold-style models.

48 blocks · 4 heads · N×N×N cube, averaged over j into an N×N map

Triangle attention (ending)

The same mechanism as "starting", but from j instead of i: the two directions complement each other to constrain the geometry of the triangle (i, j, k).

48 blocks · 4 heads · N×N×N cube, averaged over j into an N×N map

Diffusion Transformer (token)

While the 3D coordinates are generated, which residues influence each other at the token level, captured at a representative noise level in the middle of the denoising rollout.

24 blocks · 16 heads · N×N matrix, one step out of ~200

Other mechanisms of the model

not captured by the explorer, but useful to understand the whole

MSA Pair-Weighted Averaging

The AlphaFold3 MSA module does not use classic self-attention between homologous sequences: it averages them with weights taken directly from z, without any Query·Key product.

4 blocks · no QK attention

AdaLN · conditioning the diffusion transformer

In the diffusion module, the normalisation of each token is modulated by the single representation s, so that denoising takes each residue's context into account.

How pLDDT is computed

The confidence score shown on each structure is not a simple probability: it is an expected value over confidence bins, computed by a dedicated head.
